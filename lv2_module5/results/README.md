# results — 결과물

## 2. 설정 및 추적 성능 비교표

- 목적: 설정 변화가 검출과 추적 결과에 미친 영향을 근거로 설명합니다.
- 필수 구성: HSV 범위·면적 임계값, 카메라 해상도, 모터 ID·baud·각도 제한, 제어 주기와 속도 제한, Kp 2종의 비교를 기록합니다. Kp별 3회씩 총 6회 측정하고 반복별 결과를 남깁니다.
- 저장 위치: [config/](../config/)에 사용한 설정, [results/](./)에 비교표·그래프, [report.md](../report.md)에 해석을 기록합니다.
- 확인 방법: 표의 각 행에서 실제 설정 파일과 원본 CSV를 찾을 수 있고, 동일 조건에서 비교했는지 확인할 수 있어야 합니다.

## 3. 검출·추적·안전 동작 검증 결과

- 목적: 정상 추적과 목표 소실 시 안전 정지·복구를 확인합니다.
- 필수 구성: 정상·대상 없음·가림 장면, 30초 정상 추적, 2초 가림 5회, 토픽 중단 1회, 제어 통신 중단 1회의 기록을 포함합니다. 검출 판정 30프레임과 대상 없는 10프레임의 근거, FPS·추적 오차·유효 추적 비율·복구 결과를 함께 제출합니다.
- 저장 위치: [results/](./)에 원본 CSV·장면 이미지·그래프·시험 결과표를 저장하고, 영상은 파일 또는 접근 가능한 링크로 연결합니다.
- 확인 방법: 측정 구간·단위·산식·반복 횟수와 실패 결과를 확인할 수 있어야 합니다. 사전에 정한 조건과 다른 시험은 차이를 명시합니다.

## 4. ROS2 bag 및 재현 기록

- 목적: 성공과 목표 소실 상황을 다시 검증할 수 있도록 합니다.
- 필수 구성: 성공·소실 상황의 10~30초 bag, metadata.yaml과 모든 데이터 파일, 기록한 토픽·메시지 형식·재생 명령, 재현 결과를 포함합니다. 입력 재처리와 출력 재분석을 구분하고, 재생 시 모터 출력을 비활성화합니다.
- 저장 위치: [recordings/](../recordings/README.md)에 파일 또는 다운로드 링크·체크섬·설명을 두고 [README.md](../README.md)에서 연결합니다.
- 확인 방법: 다른 팀원이 bag을 내려받아 재생하고 원본과 재현 결과의 일치·차이를 [report.md](../report.md)에 기록합니다.
