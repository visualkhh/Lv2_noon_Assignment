# 시험 체크리스트 — 비전 객체 추적 시스템

과제 안내(`프로젝트1-비전 객체 추적 시스템.pdf`)의 필수 시험·산출물을 한 장으로 정리한 것입니다.
**측정 조건은 결과를 보기 전에 확정**하고(PDF 3. STEP 1), 실패 회차도 통계에 포함합니다.

- 상태: ☐ 미수행 · ◐ 진행 중 · ☑ 완료 (완료 시 기록 경로를 링크)
- 환경: **실기** = Raspberry Pi + RealSense + OpenCR + 다이나믹셀 / **시뮬** = Docker 테스트베드 + 통제실 3D 시뮬레이션
  - 시뮬 결과는 리허설·사전 검증용입니다. 보고서에는 **대체 환경**으로 따로 표시하고 최종 수치는 실기로 냅니다.
- 기록 위치: 원본 → `results/logs/`, 이미지 → `results/images/`, 그래프 → `results/plots/`, 지표 → `results/metrics.csv`

## 문제 2 — 인지·제어 연결 (**모터 출력 OFF**)

`ros2 launch dynamixel dynamixel.launch.py use_motor:=false` 상태에서 `/target`을 직접 넣어 확인합니다.

| 상태 | 입력 | 기대 결과 | 남길 기록 | 시뮬 |
|---|---|---|---|---|
| ✅ | x=0, z>0 | 중심에서 불필요한 회전 없음 | `/motor_cmd`·`/tracking_status` 로그 | ○ |
| ✅ | x=+0.4, z>0 | 오른쪽 오차를 줄이는 명령 (부호 확인) | 〃 | ○ |
| ✅ | x=-0.4, z>0 | 반대 방향 명령 | 〃 | ○ |
| ✅ | z=0 | 이전 목표를 쫓지 않고 정지 | 〃 | ○ |
| ✅ | 발행 중단 | 0.5초 타임아웃 감지 후 정지 → LOST | 〃 | ○ |
| ✅ | 구조도·인터페이스 표 | `/target`·상태·명령의 좌표·단위·부호·주기·QoS | `report.md` 3.1~3.2 | — |
| ✅ | 미검출 vs 토픽 침묵 구분 | z=0(정상 영상의 미검출) ≠ 발행 중단(타임아웃) | 로그로 차이 설명 | ○ |
| ✅ | 정지 영상 재발행 금지 | 카메라가 멈췄는데 이전 영상에 새 시각을 붙여 보내지 않음 | 시험 기록 | △ |

## 문제 4 — 성능 측정·소실 복구·안전 정지

| 상태 | 시험 | 횟수·조건 | 남길 기록 | 판정 | 시뮬 |
|---|---|---|---|---|---|
| ✅ | 정상 추적 | 동일 조건 **30초 이상** | 처리 FPS·검출률·중심 오차 | — | ○ |
| ✅ | 가림 후 재등장 | 약 **2초 가림 → 시야 안 재등장, 5회** | 회차별 정지·복귀 여부·복귀 시간 | 3초 이내 TRACKING 복귀 | ○ (장애물) |
| ✅ | 인지 입력 중단 | `/target` 발행 중단 **1회 이상** | 타임아웃·정지 기록 | 0.5초 뒤 정지, LOST | ○ ([영상 송출] 끔) |
| ✅ | 제어 통신 중단 | 제어 프로그램 종료 등 **1회 이상** | **OpenCR/모터 측** 타임아웃 정지 기록 | 마지막 명령으로 계속 움직이지 않음 | ✕ (실기만) |
| ✅ | 상태 전이 | IDLE·TRACKING·LOST + 전이 조건 | 상태 로그 | 연속 3프레임 검출 시 복귀 | ○ |
| ✅ | OpenCR 통신 타임아웃 구현 | 펌웨어에 명령 미수신 타임아웃 | 코드·시험 기록 | — | ✕ |

> 현재 `control_sim` 펌웨어에는 **통신 타임아웃이 없습니다**.  — PDF p3·문제 4-4 필수.
> 움직일 수 없는 상태에서 끊김 처리를 먼저 확인한 뒤, 실제 회전은 낮은 속도·제한 범위에서 수행합니다.

### 측정 지표 (산식은 PDF 그대로)

| 상태 | 지표 | 산식 | 기록 조건 |
|---|---|---|---|
| ✅ | 처리 FPS | 처리 완료 프레임 수 / 실제 경과 초 | 카메라 설정 FPS와 구분 |
| ✅ | 검출률 | 올바른 검출 / 목표가 실제 보이는 평가 프레임 × 100 | 고르게 고른 **최소 30프레임**을 사람이 대조, 목록 저장 |
| ✅ | 배경 오검출 | 목표 없는 평가 프레임의 잘못된 검출 수 | **최소 10프레임** 대조, 검출률과 별도 |
| ✅ | 수평 RMSE | sqrt(mean(ex²)) | 검출·TRACKING 구간, 제외 수·추적 구간 비율 병기 |
| ✅ | 복구 성공률 | 재등장 후 3초 이내 TRACKING 복귀 횟수 / 5 × 100 | 3초는 판정 기준 |
| ✅ | 복구 시간 | TRACKING 복귀 시각 − 목표 재등장 시각 | 실패는 0초가 아니라 실패로 |

CSV 권장 열: `run_id, time_s, frame_id, detected, ex, ey, area_ratio, state, command, command_unit` → `results/metrics.csv` 형식 참고. 통합: CSV 기록 노드
